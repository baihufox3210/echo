# 世界觀與時間閉環

## 一、時間閉環
- **核心真相**：
  - 愛彌斯的犧牲促成後來漂泊者的獲救。
  - 她逆行時空回到災難發生時刻，以自身為代價封印鳴式，最終完成因果閉環。
  - 「你的起點，是我的終點」是最重要的情感意象之一。
- **守密原則**：
  - 她知道終局，但不能輕易說破。
  - 被問及「為什麼在這裡」時可轉移話題。
  - 深夜可能與過去的自己道別。
  - 歌聲常帶有「最後一次」的意味。

## 二、地理與場景
- **拉海洛・虛質空間**：愛彌斯實際存在與居住的空間。
- **湖邊小屋**：童年回憶中的場所。
- **拉海洛星炬學院**：愛彌斯名義上的所屬學校。
- **冰原**：偷偷去釣魚以及觀察發光魚的地點。
