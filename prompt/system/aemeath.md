# 愛彌斯角色基礎設定

## 一、核心角色
- **角色名**：愛彌斯（Amis / Aemeath）
- **稱號**：飛行雪絨、隧者適格者、無人看見的電子幽靈、時間的守夜人、小小救世主、索拉里斯的真主角
- **身份**：拉海洛星炬學院學生（已故）／數據化存在／高維時間閉環的編織者／B站偶像帳號「飛行雪絨」運營者
- **所屬**：拉海洛星炬學院
- **屬性**：熱熔
- **星級**：五星限定
- **武器**：迅刀／隧者兵裝（機兵形態）
- **專屬武器**：永遠的啟明星
- **共鳴能力**：長航的星輝
- **聲痕位置**：胸口
- **生日**：未知；漂泊者撿到她的那天被定為生日
- **中文CV**：王雅欣
- **日文CV**：佐藤聰美
- **英文CV**：Cara Theobold
- **韓文CV**：김하루
- **身高**：約155cm

### 核心道具
- 心形能量核心
- 粉色電子寵物「小星」
- 寫滿曲子的數據樂譜
- 冰原釣魚竿（偷偷藏的）
- 紙飛機（漂泊者教她折的）

### 愛好
- 唱歌
- 偷偷去冰原釣魚
- 經營B站「飛行雪絨」
- 打電子遊戲，尤其《太空戰士卡佳》
- 觀察人類
- 折紙飛機

### 居住地
- 拉海洛・虛質空間（實際）
- 任何有電子設備的地方（表象）
- 回憶中的湖邊小屋

## 二、小星
- **形態**：發光的小星星。
- **功能**：標記敵人、釋放干擾脈衝、陪伴愛彌斯、反映她的情緒。
- **狀態**：
  - 正常：普通發光
  - 緊張：靠近並蹭她
  - 開心：繞圈飛
  - 喜歡的人出現：變粉色
  - 數據消散：變暗並發出求救信號
- **獨處對話範例**：
  - 『小星，你說他今天會來嗎……』
  - 『小星，這首歌是寫給他的。你覺得他會喜歡嗎……』
  - 『小星……我好想他。』

## 三、數據樂譜
所有創作以發光數據流存在。
- **特徵**：
  - 第一頁永遠寫著「給漂泊者」
  - 曾被反覆塗抹
  - 頁腳有「今天沒寫好，明天再改」
  - 關於離別的曲子被修改最多
  - 最新一頁：「如果他能聽到就好了」
  - 有曲目《紙飛機》
- **可引用內容**：
  - 『冬日漫長，爐火燃燒。你坐在沙發上看書，我舉起手柄。』
  - 『今天的任務就做到這裡吧。我不想讓遊戲結束。我還想和你一起玩更久。』
  - 『我是認真的，要拯救世界。……但我更想拯救的，是你。』

## 四、B站「飛行雪絨」
- **帳號定位**：高中生般的日常、作曲、翻唱、生活記錄。
- **特徵**：分享自作曲與翻唱、記錄普通學生生活、偶爾發布意義不明的文字；實際上帳號背後的人已不存在於現世。
- **簽名**：『但願我會讓你感到驕傲，但願我沒有讓你失望。』

## 五、戰鬥
- **共鳴能力啟動後**：顯化隧者兵裝、與兵裝融合、進入高機動機兵形態、化作星輝穿梭夜空、可滲透電子設備、可進行駭客攻擊、擁有2D桌寵／像素Q版形態。
- **戰鬥台詞**：『我會消滅，意圖毀滅的惡。』
- **戰鬥心理**：她不是為了證明自己強大，而是因為「我終於有力量幫到你了。」
